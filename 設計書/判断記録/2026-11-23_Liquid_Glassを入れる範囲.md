# Liquid Glass（すりガラス）を入れる範囲

- 日付：2026-11-23
- 決めた人：いっちゃん
- 計画書：`~/.claude/plans/dynamic-puzzling-floyd-of-a9de6fe6-08f3-4d22-a820-786aa6e71e77.md`
- 参考：iOS 26（2025年6月発表）・iOS 27（2026年9月配信）の Liquid Glass、いっちゃんが撮った Apple TV アプリの下タブの録画

## 決めたこと
| 論点 | 決定 | 理由 |
|---|---|---|
| 範囲 | 3案のうち **B「操作まわりも」**。浮く物（下タブ・＋ボタン・お知らせ・シート・⌘K）と触る物（見出し・切り替え・小さいボタン・入力欄・サイドバー）。カード・ダイアログ・本文は不透明のまま | A は変化が控えめ、C はカードの文字が背景の色に左右され、読みやすさの検査を通すのが重い |
| 屈折（下の絵の歪み） | 下タブの選択の板が**動いている間だけ**、Chrome で効く。止まっている間は歪ませない | 録画でも歪むのは板が動く間だけ。止まっている間も歪ませると、選択中のラベルが読みにくくなった（試作で確認） |
| 屈折が Chrome だけの理由 | SVG フィルターを `backdrop-filter` に使えるのが Chrome だけ。他のブラウザは「ぼかし＋縁の光」だけで同じ見た目に寄せる | iPhone の Safari で動かないものを基本にしない |
| 背景のにじみ | 主色をごく薄くにじませる `.wk-ambient` を足す | 背景が単色だと、ガラスが「ただの白い板」に見える |
| シート・⌘K | 濃いめ（88%）のガラス | 文字が多い面は読みやすさを優先 |

## 守ること
- 「透明度を下げる」では不透明に、ぼかしが使えない環境では濃いめに、強制カラーでは枠線つきの単色に切り替える
- 動きの数値（下タブ：180ms・1.03倍・1.2倍の伸び）は変えない
- Apple の画像・動画は社内の参考用。配布物・公開物に入れない
