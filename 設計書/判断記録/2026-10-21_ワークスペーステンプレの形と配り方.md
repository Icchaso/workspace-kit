## 決めたこと
| 論点 | 決定 | 理由 |
|---|---|---|
| 渡す相手 | 最初から講座生・お客様に配る | 講座・受託の付加価値にする |
| 形 | 新規の雛形＋既存ツールへの後付け、の両方を1つのスキルから呼ぶ | 新しく作る人と、もう作ってしまった人の両方に効かせる |
| 画面の型 | 共通の骨格（画面幅で3段階に変形）＋ A 指令室・B 現場・C AI相棒 を全部同梱 | 1つのツールの中でも画面ごとに向く型が違う（デモで実証） |
| テーマ | たくさん選べる（awesome-design-skills の67種＝MIT を日本語対応に変換） | 案件ごとに雰囲気を変えたい |
| 配布の芯 | shadcn registry（`npx shadcn add <URL>`）＋ Claude Code プラグイン | 部品のソースが相手のアプリに直接入り、後から自由に直せる |
| デモ | タスク管理ツール（2026-10-21 追加） | 型・テーマ・PC/スマホの違いを1つの題材で触って分かる |

## 守ること
- 受託・他社案件のコードはコピーしない。作法だけ参考にして書き直す（配布物に他社の著作物を混ぜない）
- 第三者の著作権表示（awesome-design-skills・shadcn＝MIT、フォント＝OFL）を `THIRD_PARTY_NOTICES` にまとめる
- ライセンス・価格・利用規約はいっちゃんが決める。規約は事務ちゃんのたたき台 → 弁護士確認
- 公開前にガード君の一次チェック（秘密の値・顧客名・案件名が混ざっていないか）

## 2026-10-21 追記（下タブの動きは iOS 26 版 Instagram が基準）
いっちゃんの録画（Instagram iOS 26・30fps）を1コマずつ測って数値にした。実装は `apps/starter/src/components/shell/bottom-tab-bar.tsx`、合否は `scripts/check-ui.mjs` が数値で出す。
| 場面 | 決めた動き | 実測（雛形・390px） |
|---|---|---|
| 指が触れた瞬間 | 押したタブが選択表示になり、バー全体が 1.03 倍にふくらむ（0.12秒） | 選択表示 3ms／バー 1.028倍 |
| 指を離した瞬間 | 画面を切り替える。中身はフェードも横すべりもしない（即移動） | 見出しが変わるまで 約43ms（離してから） |
| 選択の丸い板 | バネ 0.18秒・揺れ無しで滑る。速い間だけ横に伸びて（最大1.25倍）少し淡くなる | 止まるまで 176ms／伸び 1.20倍 |
| 押さえたまま横になぞる | 板が指についてきて少し大きくなる（1.1倍）。離したタブへ移る | — |
| 動きを減らす設定 | 板は瞬間移動、ふくらみ・伸び無し | 9ms／1.00倍 |
- 合格の線：選択表示 50ms 以内／板 120〜260ms／伸び 1.12倍以上／離してから画面切り替え 150ms 未満
- 実機（iPhone Safari）での手触りの確認はまだ

## 2026-10-21 追記（段階3：画面の型 A/B/C で決めた作法）
| 決めたこと | 理由 |
|---|---|
| 長押しの操作シートは「指を離したとき」に開く（押している間は物が少し沈んで震えるだけ） | 押したまま開くと、指を離した瞬間にシートが閉じた（自動チェックで発見） |
| 削除・明日に回す・完了は確認を挟まず、お知らせの「取り消す」で戻す。確認ダイアログは元に戻せない操作（見本データに戻す）だけ | 1日に何十回もする操作を止めない |
| 一覧の絞り込みと選んだタスクは URL に入れる（`?f=today&id=3`） | 再読み込み・共有・⌘K からの移動で同じ画面に戻れる |
| マウスは「…」でその場のメニュー、指は長押しか「…」で下からの操作シート | 指でもマウスでも同じ操作に2手以内で届く |
| AI への入力は、PC は Enter で送る（Shift+Enter で改行）、指の端末は送るボタン（Enter は改行） | スマホの Enter で書きかけを誤送信しない |
| 土台の CSS は `@layer base` に入れる | 層の外に置くと Tailwind の `outline-none` などで打ち消せない（⌘K の入力欄に青枠が出た） |
| 日本語は `word-break: auto-phrase`（文節で折り返す） | 「ヒーロ／ー画像」のような切れ方を防ぐ |
