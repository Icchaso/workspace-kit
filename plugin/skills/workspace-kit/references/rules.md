# 画面を作るときの数値と作法

見本（https://workspace-kit.vercel.app/kit）・トークン（`workspace-kit.css`）・検査台本と同じ数値。迷ったら見本の画面（`components/views/`）を真似る。

## 色は必ずトークンを通す
部品に色コードや `bg-blue-600` のような色名を書かない。テーマを変えたときに、その部品だけ取り残される。
| 使う場所 | クラス | 中身 |
|---|---|---|
| 画面の地 | `bg-canvas` | いちばん奥 |
| サイドバー・アイコン列 | `bg-sidebar` | |
| カード・パネル・シート | `bg-surface` | |
| ホバー・弱い塗り | `bg-surface-2` | |
| 区切り線・枠 | `border-line` | |
| 本文／補足／ラベル・日付 | `text-fg`／`text-fg-2`／`text-fg-3` | どれも白地で 4.5:1 以上 |
| 主ボタン | `bg-accent text-on-accent` | 1画面に1つまで |
| 選択中・弱い強調 | `bg-accent-soft text-accent-text` | |
| 状態 | `text-ok`・`text-warn`・`text-danger`（地は `-soft`） | ブランド色と別に固定 |
| 重なりの影・暗幕 | `shadow-float`・`bg-scrim` | |
ブランド色を変えるときは `--wk-accent`・`--wk-on-accent`・`--wk-accent-soft`・`--wk-accent-text` の4つだけ（ライトとダークの両方）。

## 大きさ
| 物 | 値 | クラス／変数 |
|---|---|---|
| 押せる物の高さ | マウス 36px／指 44px（画面幅ではなく「指かマウスか」で自動） | `h-hit`・`min-h-hit`・`w-hit` |
| 一覧の行 | マウス 48px（詰める設定 40px）／指 56px（詰める設定 48px） | `--wk-row` |
| 文字 | 12（これより小さくしない）・13・15（本文）・18・24px | `--wk-text-*` |
| 入力欄の文字 | 16px 以上（未満だと iPhone が勝手に拡大する） | 土台の CSS で自動 |
| 角丸 | 6・10・14px、丸い物は 999px。入れ子は「親の角丸 − 余白」 | `rounded-sm`・`rounded-md`・`rounded-lg` |
| 画面の横の余白 | スマホ 16px 以上 | |

## 骨格（3段階）
| 幅 | ナビ | 本文の左 |
|---|---|---|
| 767px 以下 | 下タブ（浮いた丸いバー・5項目まで。6つ以上かアカウントがあるときは先頭4つ＋「もっと」のシート） | 0。下にタブの分の余白 |
| 768〜1279px | アイコン列 72px | 72px |
| 1280px 以上 | サイドバー 240px（畳むとアイコン列） | 240px |
- どの幅でもナビは必ず1つ見える。項目と順番は全部同じ（`config/nav.ts` の1か所で決める）
- Tailwind の切り替え点は `rail:`（768px〜）と `side:`（1280px〜）、未満は `max-rail:`・`max-side:`。指の端末だけ変えるときは `pointer-coarse:`
- 上に貼り付く見出しだけ半透明＋ぼかし（`wk-glass-top`）。本文の面は不透明。「透明度を下げる」設定では不透明になる
- 画面の高さは `100dvh`、下端は `env(safe-area-inset-bottom)` を足す

## 動き
| 場面 | 値 |
|---|---|
| 押し縮み | 120ms・0.97倍（`active:scale-[0.97]`） |
| 色・ホバー | 160ms |
| 出し入れ | 240ms・`--wk-ease-out`（cubic-bezier(0.23, 1, 0.32, 1)） |
| シート・引き出し | 420ms・`--wk-ease-drawer`（cubic-bezier(0.32, 0.72, 0, 1)） |
| 下タブ | 指が触れた瞬間に選択表示（50ms 以内）。丸い板はバネで 120〜260ms で止まり、途中で横に 1.12倍以上伸びる。押している間バー全体が 1.03倍。指を離したらすぐ画面を切り替える（150ms 未満。中身はフェードも横すべりもしない） |
| 読み込みの骨 | 150ms 待ってから出す（速いときにチラつかせない） |
| 動きを減らす設定 | 動きはほぼ 0（状態の変化だけ残す） |
1日に何十回もする操作（画面の切り替え・一覧の選択）には動きを付けない。

## 操作の作法
- 元に戻せる操作（削除・完了・後回し）は確認を挟まない。お知らせ（`notify("削除しました", 戻す関数)`）の「取り消す」で戻す。確認ダイアログは元に戻せない操作だけ
- 時間のかかるボタンは押した瞬間に「◯◯しています」に変え、二度押しを受け付けない（`PendingButton`）
- 一覧の絞り込みと選んだ物は URL に入れる（`?f=today&id=3`）。再読み込み・共有・⌘K からの移動で同じ画面に戻れる
- マウスは「…」のメニュー、指は長押しか「…」で下からの操作シート。指でもマウスでも2手以内で届く
- 長押しのシートは指を離したときに開く（押したまま開くと離した瞬間に閉じる）
- 入力欄の Enter：PC は送る（Shift+Enter で改行）、指の端末は改行（送るボタンで送る）。日本語の変換中の Enter では送らない（`isComposing` を見る）
- 一覧は PC では表、スマホではカードの並びに変える。詳細は PC は右のパネル、スマホは下から出るシート
- キーボード：⌘K／Ctrl+K／「/」で検索・操作、N で追加、1〜9 でナビの n 番目へ（入力中・シートが開いている間は効かない）
- 日本語は文節で折り返す（土台の CSS の `word-break: auto-phrase`）。見出しは `text-wrap: balance`
- 土台の CSS は `@layer base` に入れる（層の外に置くと Tailwind のクラスで打ち消せなくなる）
- 空の状態には「次に何をすればよいか」と主ボタンを置く（`EmptyState`）
